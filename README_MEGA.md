# Nível 1 — Materiais do Jogo

Esta pasta reúne os materiais atualmente disponibilizados aos jogadores do projeto **Nível 1**.

A organização ainda está em desenvolvimento e poderá ser modificada conforme o jogo evoluir.

## Organização

Os materiais podem ser organizados de diferentes formas para facilitar a consulta:

* **Por personagem:** materiais específicos de cada personagem.
* **Por classe:** materiais disponíveis para cada classe.
* **Por conceito:** perícias, habilidades, magias, equipamentos e outros tipos de material.

Uma mesma carta pode aparecer em mais de um local. **Essa redundância é intencional**, pois facilita encontrar os materiais de diferentes maneiras.

## Arquivadas

As pastas `Arquivadas/` contêm versões substituídas ou descartadas.

Esses arquivos não devem ser considerados a versão atual, salvo indicação do Mestre.

## Nomes dos arquivos

Os nomes das cartas poderão ser padronizados ou modificados ao longo do desenvolvimento para facilitar organização, pesquisa e futuras formas de automação.

## Importante

A estrutura do MEGA é **flexível e provisória**. Ela existe para facilitar o acesso aos materiais durante o jogo e poderá mudar conforme novas necessidades surgirem.

Em caso de dúvida sobre qual versão utilizar, consulte o Mestre.
